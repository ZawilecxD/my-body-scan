# Plan review: ui-rebrand

Reviewed: `plan.md` against `change.md` (`type: feature`), Stitch research, `design-handoff.md`, standards (`minimal-implementation`, `conventions`, `navigation`, `sqlite`), lessons (splash `finally`, nav ref-guard), and as-built routes (`src/app/_layout.tsx`, `injuries/new.tsx`, `landmarks/index.tsx`, `scripts/android-emu.sh`). No `frame.md`.

## Verdict

**Not clean.** The tab/stack seam and visual-only scope are sound, but the plan is not executable as written: it names a lint gate that is not installed, an icon package that is not in the lockfile, and a `formSheet` create flow that collides with Android header limits plus `router.replace` from the catalog. Worth executing **after** Critical fixes via `/11x-review-triage`.

## Findings

### Critical

1. **`npm run lint` is not a working automated gate**  
   There is no ESLint / `eslint-config-expo` in the lockfile and no `eslint.config.*`. `expo lint` on a bare repo is an interactive installer. Current State and every phase treat `npm run lint` as today’s command; illness-disease-log correctly gated on `npx tsc --noEmit` only.  
   **Fix:** Drop lint from all five success-criteria blocks, **or** add a Phase 1 step to install `eslint` + `eslint-config-expo`, commit a config, and baseline today’s tree. Do not let an agent hang in the lint wizard mid-implement.

2. **Icon source is unspecified for Expo Go**  
   `scripts/android-emu.sh` runs **Expo Go SDK 57** (no `android/` / no dev client). Approach says `@expo/vector-icons` is “Expo-provided”; it is **not** in `package-lock.json`. Phase 1 only adds Google Fonts packages.  
   **Fix:** Phase 1 decision: `npx expo install` the icon set Expo Go actually ships, **or** reuse already-pinned `expo-symbols` (used in `src/app/map/[region].tsx`) / `react-native-svg` for the small glyph set. Record Expo Go as the run target.

3. **`formSheet` on Android cannot host the current create header**  
   Expo Router: native stack headers are not supported inside Android form sheets. `src/app/injuries/new.tsx` puts title and the missing-landmark back path in `<Stack.Screen>`. `fitToContents` also forbids `flex: 1` (clashes with the 160px description field + keyboard). Android caps detents at three.  
   **Fix:** Phase 3: `presentation: 'formSheet'` with numeric detents (e.g. `[0.6, 1]`), **in-sheet** title / Cancel / Save, no `Stack.Screen` header. Keep the missing-landmark error inside the sheet body.

4. **`/injuries/new` cannot stay a sheet and keep `replace` navigation**  
   Catalog (`src/app/landmarks/index.tsx`) `router.replace`s onto `/injuries/new`. Save then `replace`s to `/injuries/[id]`. One route option applies to both region-Log and catalog. Cross-presentation `replace` can leave sheet geometry on detail or drop the stack behind the sheet.  
   **Fix:** Sheet-everywhere: catalog `push`es create; save **dismisses** the sheet then `push`es detail (e.g. `dismissTo` tabs then `push`). Rewrite the Phase 3 save contract — do not keep `replace` to detail.

5. **Tab shell is missing three root-layout contracts**  
   `_layout.tsx` is a bare `<Stack />`. Without `headerShown: false` on `(tabs)`, users get **double headers**. Modal create needs `unstable_settings.anchor = '(tabs)'` or the screen behind the sheet is wiped. Moved screens still use `<Stack.Screen>`; after the move the nearest navigator is Tabs — `tsc` will not catch `Stack.Screen` vs `Tabs.Screen`.  
   **Fix:** Name these under Phase 2 `_layout.tsx`: hide root header on `(tabs)`; set `anchor`; switch moved files to `Tabs.Screen`. Manual: “each tab shows exactly one header.”

6. **Typed routes make a post-move `tsc` pass unreliable**  
   `app.json` `experiments.typedRoutes: true`; `.expo/types` is regenerated by Metro, not `tsc`. Moving three routes and immediately running `tsc` checks the new tree against the old union.  
   **Fix:** Phase 2 automated criterion: start Metro once to refresh `.expo/types`, then `npx tsc --noEmit`.

### Suggestion

7. **Phase 1 primitives violate `minimal-implementation.md`**  
   Six components (`AppButton`, `SegmentedControl`, `Card`, `Chip`, `TextField`, `IconButton`) ship with zero callers; first use is Phases 3–5. “≥2 callers planned” is the loophole the standard closes. `theme.ts` already exports unused `BottomTabInset` / `MaxContentWidth`.  
   **Fix:** Phase 1 = tokens, fonts, `Themed*` role mapping only. Extract primitives when a second caller appears (Phase 2: `IconButton`; Phase 3: the rest). Reuse inline `SegmentButton` until then.

8. **Phase 2 home contract contradicts itself**  
   “Chrome first / restyle OK if touched once / prefer one restyle in phase 3 / placeholder FAB” is three instructions. Not dual-write of data; it is a double-edit of `index.tsx`.  
   **Fix:** Phase 2 = move + replace header cluster with Summary/Backup icons + **working** Log injury FAB (existing `navigating` ref). Layout/data untouched until Phase 3.

9. **“Hide tab bar on push” invites a `tabBarStyle` hack**  
   Sibling stack routes covering `(tabs)` already hide the tab bar. The current wording steers implementers toward nested-tab hacks.  
   **Fix:** State: detail routes stay **siblings** of `(tabs)` in the root Stack. No `tabBarStyle: { display: 'none' }`.

10. **Illness tab filename is an “or”**  
    `(tabs)/illnesses.tsx` vs `(tabs)/illnesses/index.tsx` are not equivalent with leftover `src/app/illnesses/new` and `[id]`.  
    **Fix:** Commit to leaf `src/app/(tabs)/illnesses.tsx`; keep `illnesses/new` and `illnesses/[id]` as root-stack siblings.

11. **Splash hide contract is incomplete once fonts load**  
    `hideAsync` is only in `onInit` `finally`. If SQLite never opens, `onInit` does not run. If `useFonts` fails and the tree returns `null`, splash sticks (lesson applies; fonts add a new path).  
    **Fix:** Hide splash when `(fontsLoaded || fontError) && (dbReady || dbError)`; show font error in UI. Consider tinting splash `#208AEF` → primary in Phase 1.

12. **No `frame.md` pins Expo Go / gate / abort**  
    Research left “Expo Go vs dev client” open; that constraint drives C2–C3. Illness change used `frame.md` to pin `tsc` as the gate.  
    **Fix:** Short `frame.md`: Expo Go SDK 57, StyleSheet+tokens, icon choice, automated gate = `tsc`, abort-if form-sheet keyboard is unusable on emulator.

13. **Create Save still uses `useState` for re-entry**  
    `injuries/new.tsx` (and illness create) gate on `isSaving` state; `navigation.md` forbids that. Plan treats “double-tap Save guarded” as already true.  
    **Fix:** Phase 3/4 bullet: `saving` ref, same pattern as home `navigating`.

### Nice-to-have

14. **Screenshots as regression** — `tsc` does not catch a bad rebrand. One light/dark capture per phase against Stitch PNGs.

15. **Leave unused `@expo/ui` alone** — drive-by dep removal is a separate change. Do not resurrect `BottomTabInset`; pad home with tab-bar height / safe area.

16. **`landmarks/[id].tsx`** — design-handoff says unused. Restyle or delete; drop the plan’s “if still reachable.”

## Architectural fitness

- **Right seam:** `(tabs)` roots + stack siblings for detail. Do not nest injury/illness detail inside tabs.
- **Type gate:** `feature` — no TDD/rollback required. Correct.
- **Wrong seam:** speculative `src/components/ui/` in Phase 1; `formSheet` without Android header/nav rewrite.
- **Honors:** visual-only scope, keep PNG map, no schema, Stitch 4-tab / Settings / rename excluded.
- **Does not honor yet:** `minimal-implementation` (premature primitives), `conventions` (lint/icon deps not actually present), `navigation` (Save ref).
